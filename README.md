# COSC-4371# COSC-4371
-- This Project answers the security question: Can a prompt-injection detector trained on one dataset still catch injections from other sources, including injections obfuscated with zero-width characters, homoglyphs, or base64 encoding, at a false-alarm rate low enough for screening real user prompts?--

This file runs several uses to models logistical regression and (later on SVM) evaluate the overall performance of each model trained on different training data.
